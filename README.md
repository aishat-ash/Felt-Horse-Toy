# Игрушка лошади фетр

Иструкция по созданию игрушки лошади из фетра

## Выкройка 

![Выкройка игрушки](horse_pattern.jpeg)

Это чертёж будущей игрушки, нарисруйте выкройки согласно указанным размерам.

## Вырезание деталей из выкройки

Вырежьте из фетра детали будущей игрушки. Затем сравните получившиеся шаблоны, выровните их, чтобы они соответствовали друг другу по размеру и форме. 

## Вышивание деталей

Вышиваем по технике "обмёточный шов".
